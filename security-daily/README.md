# 🛠️ Security Daily

A daily build log of hands-on security projects based on **current, real-world vulnerabilities** across four tracks:

| Track | Focus |
|---|---|
| 🤖 **Machine Learning** | AI/ML security: adversarial ML, LLM risks (OWASP LLM Top 10, MITRE ATLAS), ML-powered detection |
| ⚙️ **Automation** | Security pipelines: alert enrichment, vulnerability triage, CI/CD security checks |
| 📜 **Scripting** | Python / C / JavaScript tooling: parsers, scanners, log analyzers, IOC extractors |
| 🎯 **Red Teaming** | Lab-only adversary emulation mapped to MITRE ATT&CK, with detections for every technique |

Each project recreates the **bug class** behind a recent CVE or incident in a small, purpose-built lab. Every project ships with a **defensive deliverable**: a detection rule, a patch, or a hardening guide.
